# 채택 명세와 제품 설정

주 빌드가 소비하는 대상 명세와 설정을 관리한다. 형식과 파일 분할은 프로젝트가 정하며, 코드나 다른 자료가 이미 소유한 값은 그 위치를 참조한다.

채택 명세에는 지원 원본과 소비 경로, 확인한 구조·주소·경계·매핑, 근거 범위와 적용·재검토 조건을 남긴다. 빌드는 이 조건을 검사하며, 원본 불일치나 반례로 명세를 적용할 수 없으면 해당 결과 생성을 중단한다.

조사 결론은 이 명세로 채택한다. 조사 절차 자체를 빌드에 편입할 때에는 선언된 입력에서 결정적인 제품 값을 만들거나 매 빌드에 필요한 검사를 수행하는 안정된 구성 요소로 확정한다.

번역 길이, 글리프 수와 배치 결과는 현재 제품 입력에서 계산한다. 설정에는 그 계산을 지배하는 선택과 제약을 두고, 대상에서 확인한 사실과 프로젝트가 선택한 글꼴·배치·표시 설정을 구분한다.
