# 채택 명세

이 디렉터리는 대상 프로젝트에 같은 역할의 위치가 없을 때, 주 빌드가 소비하는 현재 채택 명세와 선언된 제품 설정의 기본 소유 위치다. 실제 직렬화 형식과 파일 분할은 대상과 구현이 정한다.

채택 명세는 지원 원본과 소비 경로, 확정한 구조·주소·경계·매핑, 근거 범위, 적용 조건과 분석을 다시 열 조건을 식별한다. 조사에서 얻은 후보를 자동으로 고르거나 빌드 때마다 다시 발견하지 않는다. 원본이나 적용 조건이 맞지 않거나 반례가 생기면 결과 생성을 멈추고 해당 분석을 다시 연다.

번역 길이, 글리프 수, 배치 결과처럼 유효한 제품 입력에 따라 바뀌는 값은 명세에 고정하지 않는다. 주 빌드가 현재 입력에서 계산하고, 테스트는 그 값이 따라야 할 용량·정렬·참조·무결성 관계를 검사한다.

자주 조정하는 글꼴·배치·표시 값과 역공학으로 확정한 구조 값은 같은 디렉터리에 있더라도 서로 다른 입력으로 관리한다. 현재 설계를 바꾼 결과가 대상에서 확인한 사실을 덮어쓰지 않게 한다.

명세를 코드나 다른 검증된 자료가 이미 소유하면 같은 값을 이곳에 복사하지 않는다. `AGENTS.md`와 현재 상태에서 실제 소유 위치를 안내한다.
