# Sega Saturn FILM/Cinepak: 원본 확인 후 채택하는 빌드 차단 규칙

이 명세는 **모든 .CPK 파일의 보편 규칙이 아니다.** 특정 Sega Saturn 게임의 오리지널 Sega FILM 파일에서 아래 규칙이 실측될 때만 이 프로필을 채택한다. 다른 타이틀·인코더·동영상 형식은 별도 규칙을 기록한다. 일반 빌드 품질·원본 불변 정책은 [AGENTS.md](../AGENTS.md)를 따른다.

## 원본 지문 및 선결 조건

1. 원본 파일의 SHA-256, 크기, 대응 ISO extent와 런타임 소비 경로를 확인하고 지원 대상으로 선언한다. 빌드 때 다시 검사한다.
2. FILM, FDSC, STAB 헤더의 실제 오프셋·크기·타임스케일, STAB 레코드와 음성/영상 interleave를 원본에서 파싱한다. FPS는 STAB 시간축에서 계산하며 PC 인코더의 기본 FPS를 그대로 쓰지 않는다.
3. 원본에서 모든 STAB 오프셋/패킷 크기, Cinepak 각 스트립·청크 크기가 4의 배수인지 확인한다. 그렇지 않으면 **이 규칙을 적용하거나 4바이트 padding을 강행하지 않고 새 프로필로 분기한다.**
4. 원본 Cinepak 프레임에 Sega 특유의 두 바이트 확장(prefix 0x0000)이 있는지, `physical STAB packet length - Cinepak 24-bit declared length = 8`인지 확인한다. 이 값도 게임별로 확인해야 한다.
5. 비디오 해상도, 프레임 수, 스트립 수, 스트립 영역, 코드북·키프레임의 이전 프레임/스트립 의존성, PCM의 바이트 형식과 STAB의 키프레임 비트를 확인한다.

## 재인코딩/재패키징 의무 조건 (적용 프로필이 일치할 때)

- Cinepak 각 청크의 16비트 크기와 데이터, 각 스트립의 24비트 크기, 전체 Cinepak 24비트 선언 크기를 일관되게 재계산한다. **각 청크·스트립·물리 패킷 크기와 모든 STAB offset/size를 4바이트 단위로 정렬한다.** padding 후 상위 길이와 모든 offset을 다시 기록한다.
- Sega 변형에서 선언 크기는 **물리 패킷 길이 − 8**이라는 조건을 동일하게 보존한다. 일반 Cinepak 표준 길이로 임의 변경하지 않는다.
- 스트립 영역/배치, 코드북 갱신의 참조 범위, 인터프레임 플래그를 검사한다. 선택 구간을 따로 인코딩할 때 구간 시작이 독립 키프레임·코드북 상태인지 검증한다. 그렇지 않으면 원본에서부터 순차 디코딩하고 해당 구간의 코드북 상태를 유지해야 한다.
- 가능하면 변경하지 않는 영상 스트립을 **바이트 단위로 보존**하는 hybrid 방식으로 합성한다. 하이브리드의 교체 스트립 코덱 상태·독립성도 검사한다. 게임마다 스트립 수와 타일 분할 구조가 달라지므로 하이브리드 구현을 그대로 복사하지 않는다.
- FILM/FDSC 및 STAB의 오디오/비디오 레코드 순서, 원본 비디오 timestamp 하위 시간값과 duration, 전체 PCM 패킷 원본 바이트를 보존한다. 키프레임 상위 플래그를 변경할 필요가 있으면 새 비디오 패킷과 일치해야 한다.
- 원본 CPK의 ISO 고정 extent를 넘기면 정상 산출물로 내보내지 않는다. 고정 길이 유지 시 미사용 tail padding을 명시적으로 기록한다.
- 전체 출력 CPK를 *별도 디코더*로 전 구간 디코딩하고, 변경 금지 영역과 오디오, 원본과 비교 가능한 프레임·싱크를 검증한다. 디코더 통과만으로 실행 성공이라 주장하지 않는다.
- 매체를 다시 만들 때는 새 BIN/CUE 복사본의 변경 섹터·EDC/ECC·원본 밖 diff=0·추출 readback 및 xdelta 역적용 SHA-256 검증을 수행한다.

## 차단 게이트와 실행 검수

| 게이트 | 실패 판정 |
|---|---|
| 원본 지문/포맷 프로필 불일치 | 빌드 차단, 임의 보정 금지 |
| chunk/strip/frame/STAB 4바이트 정렬 오류 | 빌드 차단 |
| Sega 선언 크기 bias/strip geometry/codebook 연결 오류 | 빌드 차단 |
| PCM 한 바이트라도 변조, STAB 순서·시간축 변경 | 빌드 차단 |
| 원본 CPK 범위 초과, 디스크 섹터 침범, 패치 역적용 불일치 | 빌드 차단 |
| 전 프레임 디코딩/보호 영역/최종 자산 SHA 검증 실패 | 빌드 차단 |
| 게임 미실행 또는 사용자 미검수 | **STATIC_PASS / RUNTIME_PENDING**, 완료·배포 승인 불가 |

검증 구현의 현재 범위는 [adapters/sega-film-cpk/](../adapters/sega-film-cpk/)를 참고한다. 검사기가 다루지 않는 코드북의 의미적 올바름, VDP 영상 재생 루프, 기기 재생 동작은 별도 검사·런타임 관측으로 충족한다.
