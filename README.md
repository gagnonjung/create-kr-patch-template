# 레트로 게임 한글 패치 프로젝트 템플릿

대상 게임의 근거를 재현 가능한 제품 빌드로 연결하는 시작점이다. 플랫폼, 구현 언어, CLI와 데이터 형식은 프로젝트가 정한다. 기존 프로젝트에는 같은 역할을 맡은 구조를 유지하며 필요한 부분을 적용한다.

한글화 조사와 설계의 판단 기준은 [create-retro-game-kr-patch](https://github.com/mcpads/create-retro-game-kr-patch)를 참고한다. 이 템플릿은 프로젝트 기록과 제품 입력의 소유 위치, 이진 쓰기의 검증 조건, 선택 가능한 Rust 참고 구현을 제공한다.

## 적용 범위

실제 제품 빌드는 매체·텍스트 형식·소비 경로에 따라 구성한다. 이 템플릿에서 가져갈 공통 부분은 원본 식별, 채택 입력의 재현, 쓰기 검증과 정확한 산출물에 연결된 증거다. `patch-guard`는 이 중 작은 검증 예제이며, 기존 패처나 검증 라이브러리가 같은 조건을 충족하면 그것을 사용한다.

프로젝트의 빌드 진입점은 선언한 원본과 채택 입력에서 게임 산출물과 검증 보고서를 만들도록 연결한다. 배포 패치를 만들 때는 지원 원본에 다시 적용한 결과가 검증한 게임 산출물과 일치하는지 확인한다. 압축·매체 재구성·글리프 공급과 실행 검증은 대상 프로젝트가 구현한다.

## 시작

작업 규칙과 문서 안내는 [AGENTS.md](AGENTS.md)에 있다. 새 프로젝트에서는 README를 대상 게임, 지원 원본, 현재 범위와 빌드 진입점으로 교체하고 현재 상태를 기록한다. 원본과 출력의 실제 위치에 맞게 `.gitignore`를 확인한다.

[reference/conformance/](reference/conformance/)에는 언어 중립 검증 사례가 있고, [reference/rust/](reference/rust/)는 이를 실행하는 참고 구현이다. 라이선스 고지를 포함한 `reference/` 전체가 독립적인 복사 단위이며, 다른 위치로 옮겨도 아래 검증 명령을 사용할 수 있다. 대상 게임의 패처와 원격 CI는 프로젝트가 구성한다. 필요한 소스·테스트·자산 디렉터리는 해당 구현을 채택할 때 만든다.
