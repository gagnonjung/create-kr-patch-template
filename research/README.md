# 조사와 실험

관찰, 가설, 판별 실험, 후보 스크립트와 일회성 파생물을 둔다. 결과마다 대상 원본·산출물과 조사 범위, 직접 관찰한 사실, 해석과 남은 불확실성을 식별한다. 기각한 설명도 그 근거와 함께 보존한다.

현재 질문을 가를 수 있는 관측이나 실험을 선택한다. 새 질문·관측 방법·반례가 생기면 기존 결과의 유효한 범위를 보존하며 조사를 이어간다. 반복 실행은 새로 얻을 증거를 기준으로 결정한다.

결론이나 절차를 제품 빌드에 채택하는 조건은 [config/README.md](../config/README.md)가 맡는다. 이곳의 후보와 일회성 출력은 조사 근거로 관리한다.
