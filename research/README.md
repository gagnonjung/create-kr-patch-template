# 조사와 실험

이 디렉터리는 관찰, 가설, 판별 실험, 후보 스크립트와 일회성 파생물을 둔다. 각 결과는 대상 원본과 조사 범위, 직접 관찰한 사실, 해석, 증명한 범위와 아직 증명하지 않은 범위를 구분한다.

조사 출력은 제품 빌드 입력이 아니다. 결론을 채택할 때에는 근거 범위, 적용 대상과 재검토 조건을 현재 명세에 남기고 주 빌드는 그 명세를 소비한다. 발견 절차를 재현 가능한 빌드의 일부라는 이유만으로 반복하지 않는다.

조사 절차가 선언된 입력에서 결정적인 제품 값을 만들거나 매 빌드에 필요한 검사를 시행하는 안정된 계약이 되었다면 주 빌드 구성 요소로 옮길 수 있다. 아직 후보 증거를 만드는 절차라면 적용 조건 실패, 재검토 조건이나 반례가 생겼을 때만 다시 실행한다.
