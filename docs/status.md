# 현재 상태

현재 판단과 다음 작업에 필요한 사실을 원문 근거에 연결한다. 프로젝트를 시작하면 아래 안내를 실제 상태로 교체한다.

- 대상, 지원 원본, 선언한 범위·품질·주장과 마지막 확인 시각
- 적용 중인 사람 결정과 채택 명세의 소유 위치
- 채택한 변경의 주 빌드 통합 여부와 정확한 현재 산출물
- 정적 검사·실행 관측·사람 검토·배포 판단에서 확보한 근거와 남은 조건
- 완성을 좌우하는 미해결 조건, 현재 가설과 이를 가를 다음 행동
- 대기 중인 사람 결정과 그 사이 진행 가능한 작업

과거 실험과 기각한 설명의 근거는 조사 기록이나 작업 일지에 보존하고 여기서는 현재 판단에 필요한 부분을 연결한다.

현재 템플릿은 대상 게임, 지원 원본, 제품 범위와 주 빌드를 정하지 않았다.
