# 현재 상태

이 파일은 같은 역할의 기존 체계가 없을 때 사용하는 현재 상태 기록이다. 작업 일지나 실행 로그가 아니라, 지금 무엇을 믿고 다음에 무엇을 판정할지를 보여 준다.

대상 프로젝트를 시작하면 다음 내용을 현재 사실과 원문 참조로 교체한다.

- 현재 범위, 지원 원본과 마지막 확인 시각
- 현재 제품 주장과 사람이 정한 품질·지원 범위
- 적용 중인 전략적 결정과 채택 명세의 실제 소유 위치
- 채택한 변경이 하나의 주 빌드에 반영되었는지와 정확한 현재 산출물
- 정적 검사, 실제 소비 경로, 사람 검토와 배포 판단에서 남은 조건
- 현재 막힌 이유와 가능성을 구분할 다음 관찰 또는 구현

해결된 항목과 과거 사건은 이 파일에 쌓지 않는다. 보존할 사건은 작업 일지나 실행 기록에 남기고, 상태에는 그 원문만 연결한다.

현재 템플릿은 대상 게임, 지원 원본, 제품 범위와 주 빌드를 정하지 않았다. 새 프로젝트의 첫 적용 변경에서 이 문장을 실제 상태로 교체하거나 동등한 현재 상태 위치를 `AGENTS.md`에서 안내한다.
