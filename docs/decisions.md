# 사람의 전략적 결정

이 파일은 같은 역할의 기존 기록 체계가 없을 때 사용하는 현재 결정 등록부다. 제품·한글화 범위, 품질 기준, 지원 대상, 허용할 의미·시각 손실, 알려진 한계나 큰 기술 투자와 재설계가 달라지는 선택만 기록한다. 승인된 의도를 보존하는 통상적이고 되돌릴 수 있는 구현 선택은 여기서 새 승인을 요구하지 않는다.

각 결정은 안정 ID와 상태를 갖고 다음 의미를 보존한다.

- 결정할 질문과 필요한 이유
- 적용할 제품·원본·소비 경로·모집단과 주장 범위
- 사람이 중요하게 본 품질·의미·시각·비용·시간 기준
- 기술 근거, 비용, 위험, 영향 범위와 주장 한계를 포함한 선택지
- 에이전트의 추천과 남은 불확실성
- 사람이 선택·보류·거절한 결과, 이유와 결정 기준선
- 채택 설계, 영향받는 작업, 허용한 한계와 가능한 주장
- 결정을 다시 검토할 새 증거, 실패한 전제, 비용·의도·범위 변화

채택 결정은 적용 범위 안에서 이후 판단의 휴리스틱 근거가 되지만 기술 사실이나 빌드·실행 검증을 대신하지 않는다. 재검토 조건이 생기면 기존 이유를 덮어쓰지 않고 현재 상태와 대체 결정을 연결한다.

새 프로젝트에서는 현재 결정을 기록하고, 아직 없다면 없다고 명시한다. 동등한 기록 체계를 사용하면 실제 위치를 `AGENTS.md`에서 안내한다.
