# 사람의 전략적 결정

제품·한글화 범위, 품질, 지원 대상, 허용할 손실·한계나 큰 투자가 달라지는 선택을 기록한다. 채택한 의도를 보존하는 일상적인 구현은 에이전트가 진행한다.

기록 형식은 프로젝트가 정한다. 결정마다 다음 정보를 연결한다.

- 안정 ID, 현재 상태와 적용할 제품·원본·소비 경로·주장 범위
- 결정할 질문, 현재 성과와 남은 차이, 사람이 중요하게 보는 기준
- 실행 가능한 선택지와 추천, 예상 효과·비용·위험·불확실성의 근거
- 사람이 선택·보류·거절한 결과, 이유, 정확한 근거 기준선과 영향받는 작업
- 새 증거나 의도·비용·범위 변화에 따른 재검토 조건

채택 결정은 해당 범위의 후속 작업을 이끈다. 기술 사실과 빌드·실행 검증은 별도로 입증한다. 대화에서 정한 결정도 후속 작업 전에 이 기록에 반영하고, 재검토 시 기존 이유와 대체 결정의 관계를 보존한다.

현재 템플릿에는 대상 게임에 대한 결정이 없다. 프로젝트를 시작하면 실제 결정을 기록하거나 동등한 소유 위치를 `AGENTS.md`에서 안내한다.
